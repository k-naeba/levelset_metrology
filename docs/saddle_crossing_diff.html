levelset_metrology · saddle case 5

Where the mesh and the true surface disagree

A single level-set cell with corners 0 and 2 negative (inside, magnitude s) and corners 1, 3 positive (outside, fixed at 1). A probe line runs along the bottom-face diagonal, from corner 0 to corner 2. Marching cubes always caps that saddle with two fixed triangles, one per inside corner — the true trilinear-interpolated surface does something different, and does it differently depending on s. Further down, the same probe is run against a simpler baseline cell with only one inside corner, to isolate how much of this comes from the saddle's two separate solid regions specifically.

Crossing position along the probe, as s sweeps 0.2 → 3.0

Each method reports where it thinks material starts and ends along the probe (parametric position t, 0–1). Below s = 1 both methods report two crossings, but at different positions — a sizing error. At s = 1 the trilinear pair converges to a single point and vanishes: above that threshold the true surface has reconnected and the probe never crosses it, while the fixed mesh triangulation still reports the same two-crossing gap it always does.

Why: the field itself changes topology

Each panel colors the true bilinear field on the probe's own face — blue where it's negative (inside), red where positive (outside) — with the probe diagonal drawn across it. Both axes are the face's own local coordinates, 0 to 1: x runs corner 0 → corner 1, y runs corner 0 → corner 3; the probe itself is the diagonal x = y = t, from corner 0 to corner 2. At s = 0.30 the two inside corners stay separate blue lobes, so the diagonal still crosses zero twice, just not exactly where the mesh assumes. At s = 2.00 the two lobes have merged into one connected blue region that swallows the diagonal without ever crossing zero — the mesh's two triangles are capping a gap that, on the real surface, no longer exists.

Baseline: what if there's only one solid region?

Same cell, same probe, same sweep — but only corner 0 is inside (magnitude s); corners 1, 2, 3 are all outside, fixed at 1. There's no saddle here, so marching cubes has nothing to disambiguate: it caps corner 0 with a single fixed triangle (in fact the exact same triangle as the mesh's first triangle above, since it's built from the same three edges). Both methods always report exactly one crossing, for every s — the question below isn't whether they agree, but by how much their reported position drifts apart.

Same field, one lobe instead of two

Same coloring and axes as the saddle panels above — but with only corner 0 negative, there's just one blue lobe, and it can never grow large enough to swallow the whole diagonal (corner 2 stays fixed at v = 1, so the field along the diagonal's far end never crosses zero). That's the structural reason case 1 never sees a topological disagreement, no matter how large s gets — unlike case 5, where corner 2 going negative too is exactly what let the two lobes merge.
